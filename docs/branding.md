# 🎨 Branding - BarberPro

## Conceito da Marca

### Nome
**BarberPro** - Profissionalismo e modernidade para barbearias.

### Slogan
*"Sua barbearia, seu império."*

### Valores
- **Profissionalismo:** Ferramentas sérias para negócios sérios
- **Simplicidade:** Interface intuitiva, sem complicação
- **Modernidade:** Design contemporâneo, dark mode por padrão
- **Eficiência:** Otimização de tempo para barbeiros e clientes

---

## Paleta de Cores

### Primary Colors
- **Preto Profundo:** `#0A0A0A` (Background principal)
- **Dourado:** `#D4AF37` (Accent, botões primários, destaques)
- **Branco Off:** `#F5F5F5` (Texto principal)

### Secondary Colors
- **Cinza Escuro:** `#1A1A1A` (Cards, seções)
- **Cinza Médio:** `#2A2A2A` (Borders, divisores)
- **Cinza Claro:** `#888888` (Texto secundário)

### Status Colors
- **Sucesso:** `#10B981` (Verde esmeralda)
- **Erro:** `#EF4444` (Vermelho)
- **Aviso:** `#F59E0B` (Amarelo)
- **Info:** `#3B82F6` (Azul)

---

## Tipografia

### Fontes
- **Principal:** `Inter` (Google Fonts) - Clean, moderna, legível
- **Display:** `Playfair Display` (Google Fonts) - Elegante para títulos
- **Monospace:** `JetBrains Mono` - Para código e números

### Hierarquia
```text
H1: Playfair Display, 48px, Bold
H2: Playfair Display, 36px, Bold
H3: Inter, 24px, SemiBold
Body: Inter, 16px, Regular
Small: Inter, 14px, Regular
Caption: Inter, 12px, Light

```

---

## Logo

### Conceito

Tesoura estilizada + letra "B" minimalista em dourado sobre fundo preto.

### Versões

* **Principal:** Logo completo (ícone + texto)
* **Ícone:** Apenas o símbolo (para favicon, app mobile)
* **Monocromática:** Versão em branco/preto para fundos variados

---

## Componentes Visuais

### Botões

* **Primário:** Fundo dourado, texto preto, hover com brilho
* **Secundário:** Borda dourada, fundo transparente
* **Danger:** Fundo vermelho, texto branco

### Cards

* Fundo cinza escuro (`#1A1A1A`)
* Border sutil (`#2A2A2A`)
* Border-radius: `8px`
* Sombra suave em hover

### Ícones

* **Biblioteca:** Lucide React (clean, consistente)
* **Estilo:** Outline, 24px padrão
* **Cor:** Dourado para destaques, branco para normal

---

## Dark Mode (Padrão)

O sistema é **dark-first**, com opção de light mode.

### Dark Mode

* Background: `#0A0A0A`
* Surface: `#1A1A1A`
* Text: `#F5F5F5`

### Light Mode

* Background: `#FFFFFF`
* Surface: `#F9FAFB`
* Text: `#111827`
* Accent: `#B8860B` (Dourado mais escuro para contraste)

## Tom de Voz

### Comunicação

* **Profissional mas acessível:** Tratamento por "você", sem formalidade excessiva
* **Direto ao ponto:** Mensagens claras, sem rodeios
* **Encorajador:** Celebra conquistas do barbeiro ("Parabéns! 50 agendamentos este mês!")

### Exemplos

* ✅ *"Seu próximo cliente chega em 15 minutos."*
* ✅ *"Faturamento do mês: R$ 5.420,00. Ótimo trabalho!"*
* ❌ *"O sistema informa que há um compromisso agendado."*
